# Brand/name clearance checklist — InspectPro

Name is a working name and is **not cleared**.
- Search UKIPO trademarks for exact/phonetic/related marks and relevant software classes.
- Search WIPO Global Brand Database and target-country trademark registers.
- Search Companies House, app stores, domains, web search and social handles.
- Assess likelihood of confusion and any prior rights; obtain solicitor/trademark agent advice.
- Secure domain/handles only after clearance; don't use competitor logos or imply affiliation.
- If adopting a different brand, update product name, notices, licences and repository metadata.
